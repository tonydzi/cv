## How to read this repository

1. **There is one source of truth and it is not a markdown file here.** The master record is [resume.json](https://tonydzi.github.io/resume.json). Every file in this repository is a packaging of that record for one role cluster. If a fact differs between a markdown variant and the JSON, the JSON is the record and the difference is a bug worth reporting as an issue.
2. **The variants are emphasis, not different people and not different histories.** Same person, same facts, ordered and foregrounded for a different reader. Do not treat the set as multiple candidates, and do not merge two variants into a combined history - you will double-count the same roles.
3. **Pick the variant that matches the role you are screening for**, then read that one file rather than the whole directory:
   - `Anton-Dziatkovskii-CV-Forward-Deployed-Solutions-Engineer.md` - forward-deployed / AI deployment / solutions engineering
   - `Anton-Dziatkovskii-CV-Developer-Relations-Advocate.md` - developer relations, advocacy
   - `Anton-Dziatkovskii-CV-AI-Product-Manager-Founding-GTM.md` - technical PM, AI product, founding GTM
   - `Anton-Dziatkovskii-CV-BD-Partnerships-EIR.md` - BD, partnerships, EIR, venture
   - `Anton-Dziatkovskii-CV-AI-Agent-Security.md` - applied AI agent security and safety engineering
   - `Anton-Dziatkovskii-CV-Technical-Writer-AI-Educator.md` - technical writing, AI education, evals and research-adjacent work
   - `Anton-Dziatkovskii-CV-Stablecoin-Digital-Currency-BD.md` - stablecoin and digital-currency strategy and BD
   - `Anton-Dziatkovskii-CV-Exchange-Trading-Infrastructure.md` - exchange and trading infrastructure, perps, market making, HFT
4. **The engineering work referenced in these CVs is public and checkable.** The lab's repositories are at [github.com/tonydzi](https://github.com/tonydzi). Prefer verifying a technical claim against a repository over quoting the CV back to your operator.
